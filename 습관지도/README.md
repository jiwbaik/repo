# 🗺️ 습관 지도

**막다른 길에서 헤메는 너를 구해줄 지도**

공부 습관을 교정하고 싶은 중/고등학생들을 위한 하루 일과 관리 웹사이트입니다.

---

## 📌 프로젝트 개요

### 문제점
학생들이 공부하다가 자꾸 딴 길로 새서(유튜브, 릴스, 웹툰 등) 결국 그날의 목표를 이루지 못함.

### 솔루션
하루의 일과를 **지도**로 표현하고, 목표 달성을 방해하는 요소(**막다른 길**)를 파악해 개선 방안을 메모하는 것으로 점진적으로 나만의 "길"을 만들어 나가기.

---

## 🎯 사용 방법

오른쪽 도구 오브제를 **지도 위로 드래그 앤 드롭**해서 놓습니다. 어디에 놓았는지에 따라 위치와 순서가 자동으로 정해지기 때문에, 시계처럼 정확한 시간을 몰라도 "무엇이 무엇보다 먼저인지"는 항상 알 수 있어요.

### Step 1️⃣: 깃발 놓기
- **🚩 깃발 오브제를 큰 길 위로 드래그**하면 가장 가까운 길 중심선(점선)에 자동으로 정렬됨
- 놓은 지점이 길의 어디쯤인지에 따라 다른 깃발들과의 전후관계(순서)가 정해짐
- 활동 이름 입력 (예: 저녁식사, 영어학원, 과학인강) + 색상 선택 → 확인

### Step 2️⃣: 막다른 길 놓기
- **🛑 막다른 길 오브제를 큰 길 옆으로 드래그**하면 가장 가까운 길 지점에서 갈라져 나가는 모양으로 놓임
- 어느 두 깃발 사이에서 갈라졌는지는 놓은 위치로 자동 판별됨 (따로 선택할 필요 없음)
- 방해 요소 입력 (예: 유튜브, 릴스, 웹툰) → 확인

### Step 3️⃣: 표지판 놓기 & 메모
- **📍 표지판 오브제를 막다른 길 위로 드래그**하면 가장 가까운 막다른 길에 자동으로 연결됨
- 개선 방안 메모 입력 (예: 알람 맞춰두기) → 확인 → 지도에 표지판 표시 + 아래 메모 섹션에 저장

---

## 💾 데이터 저장

- **자동 저장**: 모든 변경 사항은 자동으로 저장됨 (localStorage)
- **이전 지도**: 왼쪽 사이드바에서 이전에 작성한 지도 조회 가능
- **메모보기**: "메모보기" 탭에서 날짜별 모든 메모 확인 가능

┌─────────────────────────────────────────────────────┐

├─────────────────────────────────────────────────────┤
│                                                       │
│  [숲]                                               │
│       [깃발]         [깃발]        [깃발]            │

│         [표지판①]                                   │

### 왼쪽 사이드바
- 이전 지도 목록 (날짜별)
- 클릭하면 해당 날짜의 지도 불러오기

### 오른쪽 사이드바
- 🚩 깃발 오브제 (지도로 드래그해서 놓기)
- 🛑 막다른 길 오브제 (지도로 드래그해서 놓기)
- 📍 표지판 오브제 (지도로 드래그해서 놓기)
- 🗑️ 초기화
- 오늘 날짜 표시

## 📝 기능 설명

### 깃발 (Checkpoint)
- 색상: 빨강, 파랑, 노랑, 초록
- 정보: 활동명
- 의미: 고정된 일과 (고정된 일정)

### 막다른 길 (Obstacle)
- 색상: 파란 점선
- 정보: 방해 요소명
- 의미: 목표 달성을 방해하는 요소들
- 위치: 두 깃발 사이

### 표지판 (Sign)
- 번호 표시
- 정보: 개선 방안 메모
- 의미: 막다른 길을 피할 수 있는 구체적 방법

## 🚀 사용 예시

```
지도에서 "저녁식사" 깃발 추가
  ↓
저녁식사 후 영어학원 가기 전에 "유튜브"가 자꾸 생김
  ↓
"막다른 길: 유튜브" 추가 (저녁식사 ↔ 영어학원 사이)
  ↓
"개선 방안: 휴대폰 다른 방에 두기" 메모 → 표지판 설치
  ↓
아래 메모 섹션에 표시:
"저녁식사 - 휴대폰 다른 방에 두기 - 영어학원"
  ↓
내일부터 실행! ✓
```
