```

│                    🧑‍🎓 너온편 앱 사용                     │

                     │
                     ↓ (편지 보내기)
                     
┌────────────────────────────────────────────────────────┐
│           프론트엔드 (Frontend)                          │

                     │ HTTP POST
                     │ (JSON 데이터 전송)
                     ↓
                     
┌────────────────────────────────────────────────────────┐
│           백엔드 (Backend)                              │
│        ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━              │

│                                                        │

│                                                        │
│  5️⃣ 프론트엔드에 답변 반환                             │

                     │ HTTP Response
                     │ (JSON 답변 반환)
                     ↓
                     
┌────────────────────────────────────────────────────────┐
│           프론트엔드 (다시)                              │
│  받은 편지함에 선생님 답장 표시                          │
└────────────────────────────────────────────────────────┘
```

## 🎭 프론트엔드 vs 백엔드

### **프론트엔드 (Frontend) = 앞 (사용자가 보는 부분)**

```html
<!-- index.html (프론트엔드) -->
사용자 입력:
┌─────────────────────┐
│  편지 작성          │  ← 사용자가 이 버튼을 클릭
│  ✍️ 고민 작성      │  ← 사용자가 여기에 글을 씀
│  📬 받은 편지      │  ← 사용자가 이 버튼을 클릭
└─────────────────────┘

코드:
<div onclick="goToWriteLetter()">  ← 버튼 클릭
  <input placeholder="...">         ← 입력창
</div>

역할:
✅ 화면 그리기
✅ 버튼 클릭 받기
✅ 사용자 입력 받기
✅ 백엔드로 데이터 전송
✅ 받은 답변 표시하기
```

### **백엔드 (Backend) = 뒤 (사용자가 안 보는 부분)**

```javascript
// app.js (백엔드)
프론트엔드에서 온 데이터:
{
  studentGrade: "1학년",      ← 학년
  studentNickname: "별이",    ← 닉네임
  studentSubject: "수학",     ← 과목
  studentKeyword: "학습법",   ← 키워드
  studentLetter: "수학이..."  ← 편지 내용
}

역할:
✅ 데이터 처리
✅ 데이터베이스 조회 (teachers.json)
✅ AI API 호출
✅ 답변 생성
✅ 프론트엔드에 답변 반환
```

### **비유하면:**

```
프론트엔드 = 음식점의 "서빙 직원" 👨‍💼
  • 손님 (사용자)와 대면
  • 주문 받기 (데이터 수집)
  • 주방 (백엔드)에 주문 전달
  • 음식 받아서 손님에게 서빙 (결과 표시)

백엔드 = 음식점의 "주방" 👨‍🍳
  • 손님은 안 보는 곳
  • 주문 받기 (요청 처리)
  • 재료 준비 (데이터 찾기)
  • 요리하기 (처리/계산)
  • 완성된 음식 전달 (결과 반환)
```

## 🎓 선생님 인터뷰

### **"선생님 인터뷰"가 뭐예요?**

```
학생: "수학이 너무 어려워요..."

Claude AI: "어떤 선생님일까? 어떤 말씀을 할까?"
          → teachers.json에서 선생님 정보 찾아보기
          
teachers.json:
{
  "수학": {
    "학습법": "수학은 개념이 제일 중요합니다..."  ← 이거!
  }
}

Claude AI: "아, 이 선생님은 이런 말씀을 하시는군요!
           이걸 활용해서 답장을 만들어야겠다!"
           
최종 답장: "너는 개념을 중점적으로 공부해야 해...
           (선생님의 말씀을 자연스럽게 포함)"
```

### **파일 위치**

```
neoenpyeon/
└── backend/
    └── teachers.json  ← 여기에 모든 선생님 인터뷰가 저장됨
```

### **파일 내용 구조**

```json
{
  "과목1": {
    "키워드1": "선생님 인터뷰 내용 1",
    "키워드2": "선생님 인터뷰 내용 2"
  },
  "과목2": {
    "키워드1": "선생님 인터뷰 내용 3"
  }
}

예시:
{
  "국어": {
    "학습법": "국어는 읽고 분석하는 것이 핵심입니다...",
    "성적": "국어 성적이 안 나도 절망하지 마세요...",
    "선택과목": "확대와 축소, 언어와 매체 중..."
  },
  "수학": {
    "학습법": "수학은 개념이 제일 중요합니다...",
    "성적": "수학 성적이 안 나도 포기하지 마세요...",
    "선택과목": "미적분과 확률과 통계 중..."
  }
}
```

### **app.js에서 어떻게 사용하나?**

```javascript
// 1단계: 프론트엔드에서 데이터 받음
const { studentSubject, studentKeyword } = req.body;
// studentSubject = "수학"
// studentKeyword = "학습법"

// 2단계: teachers.json에서 찾기
const teacherInterview = teachersData[studentSubject][studentKeyword];
// teacherInterview = "수학은 개념이 제일 중요합니다..."

// 3단계: Claude API에 전달
system: `당신은 ${subject} 선생님입니다.
         다음 인터뷰 내용을 자연스럽게 활용하세요:
         "${teacherInterview}"`,

// 결과: Claude가 이 인터뷰를 바탕으로 답장 생성!
```

### **새로운 인터뷰 추가하기**

선생님 인터뷰를 더 추가하고 싶으면:

1. `backend/teachers.json` 파일 열기
2. 다음처럼 추가:

```json
{
  "국어": {
    "학습법": "기존 내용...",
    "성적": "기존 내용...",
    "선택과목": "기존 내용...",
    "새로운키워드": "여기에 새 인터뷰 작성"  ← 추가
  }
}
```

3. 파일 저장
4. 백엔드 서버 재시작 (`npm start`)

## 🤖 Claude API

### **Claude API가 뭐예요?**

```
Claude = 쌤(Anthropic이 만든 AI 챗봇)
API = Claude와 대화하는 방법

예:
프로그램 ─→ Claude API ─→ Claude AI ─→ 답변 ─→ 프로그램
         ("답장 만들어줘!")       ("좋아, 만들어줄게")
```

### **작동 과정**

```javascript
// Step 1: API 주소로 요청 보내기
const response = await axios.post(
  'https://api.anthropic.com/v1/messages',  // ← Claude의 주소
  {
    model: 'claude-3-5-sonnet-20241022',    // ← Claude의 최신 버전
    max_tokens: 500,                         // ← 답변 길이 (500토큰 = 약 150단어)
    
    // Step 2: Claude의 "성격" 정하기
    system: `당신은 수학 선생님입니다.
             학생의 고민에 따뜻하게 답장해주세요.
             다음 인터뷰를 자연스럽게 활용하세요:
             "수학은 개념이 제일 중요합니다..."`,
    
    // Step 3: Claude에게 할 질문
    messages: [
      {
        role: 'user',
        content: '학생이 보낸 편지: "수학이 너무 어려워요..."'
      }
    ]
  },
  {
    headers: {
      'x-api-key': process.env.CLAUDE_API_KEY  // ← .env의 API 키
    }
  }
);

// Step 4: Claude의 답변 받기
const teacherReply = response.data.content[0].text;
// "너의 고민을 잘 이해했어. 수학은 개념이..."
```

### **API 키는 뭐예요?**

```
API 키 = Claude를 사용하는 권한을 증명하는 비밀번호

예:
API 없음: "Claude야, 답장해줄래?"
         Claude: "누세요? 모르는 사람이네요."
         
API 있음: "Claude야, 여기 내 API 키야. 답장해줄래?"
         Claude: "아, 당신이군요! 좋아, 해드릴게!"
```

### **API 키 발급 받기**

1. https://console.anthropic.com 방문 (구글 로그인)
2. 좌측 "API keys" 클릭
3. "Create Key" 버튼
4. 나타난 키 복사
5. `.env` 파일에 입력:
```
CLAUDE_API_KEY=sk-ant-v0-abc123...
```

### **max_tokens가 뭐예요?**

```
토큰 = 단어 단위의 텍스트 조각
1 토큰 ≈ 0.3단어

max_tokens: 500
→ 약 150-200단어의 답변이 생성됨

많을수록:
✅ 더 길고 자세한 답장
❌ API 사용료 증가

적을수록:
✅ 짧고 간단한 답장
✅ API 사용료 절감
```

### **시스템 프롬프트가 뭐예요?**

```javascript
system: `당신은 수학 선생님입니다.
         학생의 고민에 따뜻하게 답장해주세요.
         ...`

이건 Claude에게 "이렇게 행동해줘"라고 지시하는 부분입니다.

없으면:
Claude: "안녕, 난 Claude야. 뭐 도와드릴까?"

있으면:
Claude: "안녕, 난 수학 선생님이야. 너의 고민을 들어볼게..."
```

## 🚀 설치 방법

### **1단계: Node.js 설치**
```bash
https://nodejs.org 방문
LTS 버전 다운로드 & 설치
```

### **2단계: Claude API 키 발급**
```
https://console.anthropic.com
→ API keys
→ Create Key
→ 복사
```

### **3단계: 파일 준비**
```
다운로드한 파일들을 이 구조로 정렬:

neoenpyeon/
├── frontend/
│   └── index.html
├── backend/
│   ├── app.js
│   ├── teachers.json
│   ├── package.json
│   └── .env
└── README.md
```

### **4단계: .env 파일 설정**
```
backend/.env 파일 열기

CLAUDE_API_KEY=sk-ant-v0-YOUR_API_KEY_HERE
↑ 여기를 실제 API 키로 바꾸기
```

### **5단계: 백엔드 설정**
```bash
# backend 폴더에서 터미널 열기
cd backend

# npm 패키지 설치
npm install

# 서버 시작
npm start

# 다음 메시지가 나오면 성공!
# 🚀 너온편 백엔드 서버 시작!

```

### **6단계: 프론트엔드 열기**
```
브라우저에서 frontend/index.html 열기
(또는 끌어서 브라우저에 드롭)
```

## 📊 데이터 흐름 정리

```
1. 학생이 "편지 보내기" 클릭
   ↓
2. 프론트엔드 (index.html)가 데이터 수집
   - 닉네임
   - 과목
   - 키워드
   - 편지 내용
   ↓
3. 백엔드 (app.js)로 POST 요청 전송
   ↓
4. 백엔드가 teachers.json에서 선생님 인터뷰 찾기
   ↓
5. Claude API에 요청
   (학생 편지 + 선생님 인터뷰 전송)
   ↓
6. Claude가 답장 생성
   ↓
7. 백엔드가 답장을 프론트엔드로 반환
   ↓
8. 프론트엔드가 화면에 표시
   ↓
9. 사용자가 "받은 편지함"에서 답장 확인!
```

## ❓ 자주 묻는 질문

### **Q: API 키를 .env에 넣는 이유는?**
```
A: 보안 때문입니다!
   
   나쁜 예: app.js에 직접 입력
   CLAUDE_API_KEY = 'sk-ant-v0-xxx...'  ← GitHub에 올라가면 위험!
   
   좋은 예: .env에 입력
   .env → .gitignore에 추가 → GitHub에 올리지 않음 ✅
```

### **Q: teachers.json은 어디에?**
```
A: backend 폴더에 있습니다.

backend/
├── app.js           ← 서버 프로그램
├── teachers.json    ← 여기! 선생님 인터뷰
├── package.json
└── .env
```

### **Q: API 사용료가 드나요?**
```
A: 처음에 $5 무료 크레딧이 있습니다!
   그 이후는 사용한 토큰에 따라 요금 발생.
   
   걱정 마세요:
   - 테스트 용도: 거의 안 들어요
   - 학교 프로젝트: 무료 크레딧으로 충분
```

### **Q: Claude API 대신 다른 AI 써도 되나요?**
```
A: 네, 하지만 코드를 바꿔야 합니다.

   현재: Claude API 사용
   변경: ChatGPT API / Google Gemini API 등
   
   모두 동작 방식은 비슷합니다.
```
